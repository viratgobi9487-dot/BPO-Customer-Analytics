# 📞 BPO Service Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing BPO customer service data and creating an interactive dashboard using Power BI.

The dashboard provides insights into customer service performance, call handling, agent performance, call status, and other key service metrics.

## 🛠️ Tools & Technologies

* Power BI
* DAX
* Power Query
* Data Cleaning
* Data Transformation
* Data Visualization

## 🔍 Data Preparation & Cleaning

* Checked the dataset for duplicate records
* Checked for missing and null values
* Verified and corrected data types
* Checked data consistency and accuracy
* Cleaned and transformed the data for analysis

## 📊 Data Analysis

* Analyzed customer service performance
* Analyzed call status and call outcomes
* Analyzed agent-wise performance
* Created KPI measures for important service metrics
* Used DAX measures for calculations and analysis
* Created interactive filters and slicers

## 📈 Dashboard Features

* KPI Cards
* Call Status Analysis
* Agent Performance Analysis
* Customer Service Analysis
* Interactive Charts
* Slicers and Filters
* Interactive Power BI Dashboard

## 🎯 Project Objective

The main objective of this project is to analyze BPO customer service data and transform it into meaningful insights using Power BI, DAX, and data visualization.
